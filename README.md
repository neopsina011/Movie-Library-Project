## Описание программы

**Movie Library** — это графическое приложение на Python для хранения информации о фильмах.

Программа позволяет:

* добавлять фильмы
* просматривать список всех фильмов
* фильтровать фильмы по жанру и году
* автоматически сохранять данные в файл

Все данные хранятся в формате JSON (`movies.json`).

---

## Требования для запуска

Перед запуском убедитесь, что у вас установлено:

* Python 3.8 или выше
* Библиотеки:

```bash
pip install tkinter
```


---

## Как запустить

1. Скачайте проект:

```bash
git clone https://github.com/neopsina011/Movie-Library-Project.git
cd Movie-Library-Project
```

2. Запустите программу:

```bash
python main.py
```

---

## Как пользоваться

После запуска откроется окно приложения.

### Добавление фильма:

1. Введите:

   * название
   * жанр
   * год
   * рейтинг (от 0 до 10)
2. Нажмите **"Добавить фильм"**

### Фильтрация:

* Введите жанр и год
* Нажмите **"Применить"**
* Для сброса нажмите **"Сброс"**

### Таблица:

* Отображает все добавленные фильмы
* Обновляется автоматически

---

## Хранение данных

* Все фильмы сохраняются в файл:

```
movies.json
```

* Данные сохраняются автоматически при добавлении

## О данных

Программа проверяет:

* заполнены ли все поля
* год — число
* рейтинг — число от 0 до 10

При ошибке выводится сообщение.
